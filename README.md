# 💼 SkillMatch – Anti-Resume

> **Skills First, Resumes Second.**

SkillMatch is a modern job search and hiring platform designed to reimagine traditional hiring practices. By letting candidates demonstrate their abilities through skill-based challenges rather than relying solely on resumes, our platform aims to eliminate bias, ensure transparency, and connect talent with opportunities based on true merit.

This is a collaborative team project driven by passionate developers, designers, and innovators dedicated to transforming the hiring landscape.

---

## 🚀 Problem Statement

### **Anti-Resume Job Platform**

Traditional hiring practices rely too heavily on resumes, keywords, and subjective evaluations—often overlooking talented candidates who do not fit conventional profiles. The Anti-Resume Job Platform tackles these challenges by:

- **Modern Screening:**  
  Replacing outdated resume reviews with practical, skill-based challenges.
  
- **Bias Reduction:**  
  Using blind matching and AI-powered analysis to assess candidates fairly and eliminate biases.
  
- **Transparency:**  
  Offering clear insights on salary ranges, company culture, and work expectations via authentic work samples and detailed project scenarios.
  
- **Continuous Improvement:**  
  Incorporating a post-hire feedback loop to continuously refine the matching process and improve hiring outcomes.

By addressing these pain points, the platform empowers candidates to showcase their true potential and enables companies to source talent that genuinely fits their work culture and needs.

## ✨ Features

- **Skill-First Approach:**  
  Candidates complete real-world, skill-based challenges that showcase their capabilities.
  
- **AI-Powered Matching:**  
  Advanced algorithms match candidates to job positions based on demonstrated skills instead of keywords.
  
- **Bias-Free Hiring:**  
  An initial blind matching process promotes fairness and diversity in candidate selection.
  
- **Transparent Insights:**  
  Detailed data on salaries, company culture, and work expectations empower candidates with informed choices.
  
- **Real-World Projects:**  
  Companies present actual work samples rather than generic job descriptions.
  
- **Feedback Loop:**  
  Post-hire feedback continuously refines the matching process to improve future outcomes.
  
- **Responsive Design:**  
  A fully responsive UI that adapts seamlessly to different devices.

## 🧪 Getting Started

Follow these steps to run SkillMatch locally:

1. **Clone the Repository:**
   git clone https://github.com/your-username/skillmatch-anti-resume.git
   cd skillmatch-anti-resume

2. Install Dependencies:
    npm install

3. Start the Development Server:
    npm run dev

Open in Your Browser:
Navigate to http://localhost:5173 (or your configured port) to view the platform.
